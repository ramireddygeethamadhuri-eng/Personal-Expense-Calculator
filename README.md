Personal Expense Calculator:

A colorful and responsive Personal Expense Calculator built using HTML, CSS, and JavaScript. It allows users to record their income and expenses, categorize expenses, and instantly view their total income, expenses, and savings.

Objectives:

1.To create a simple and user-friendly expense tracking application.

2. To record and manage personal income and expenses.

3. To categorize expenses for better financial tracking.
   
4. To automatically calculate total income, total expenses, and savings.

5.To provide a clear visual summary of personal spending.

6. To build a responsive and interactive web application using basic frontend technologies.

 Tools Used:

1. Visual Studio Code – Code development and editing

2. Web Browser – Running and testing the application
 
3. Browser Developer Tools – Debugging and testing

 Technologies Used:

1. HTML5 – Structure and content of the application

2. CSS3 – Styling, layouts, gradients, animations, and responsive design
 
3. JavaScript – Application logic, calculations, event handling, and dynamic UI updates

4. DOM Manipulation – Dynamically updating the webpage based on user input

 Features:

1. Add income with description and amount

2. Add expenses with description, amount, and category

3. Automatically calculate total income

4. Automatically calculate total expenses

5. Calculate remaining savings

6. Categorize expenses into:

   1. Food
   
   2. Transport
    
   3. Education
   
   4. Entertainment
    
   5. Shopping
  
   6. Bills
 
7. Display category-wise expense breakdown

8. Display recent expenses

9. Show the number of expense categories and recorded expenses

10. Reset all entered data
 
11. Responsive design for different screen sizes
 
12. Colorful gradient-based user interface
 
13. Interactive buttons, cards, and hover effects

Output:

The application provides an interactive dashboard displaying:

- Total Income
  
- Total Expenses

- Total Savings
 
- Expense Category Breakdown

- Recent Expenses

For example:

Total Income     : ₹5,000.00

Total Expenses   : ₹250.00

Savings          : ₹4,750.00
